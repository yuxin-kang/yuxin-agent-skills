# Digest Schema

Use this order for a daily report:

```markdown
# 机器人论文日报｜YYYY-MM-DD

> 检索窗口、来源、论文数量、总结模式和证据边界

## 今日概览

- 2–5 条真正值得关注的趋势

## 必读论文

### 1. Paper title

- 状态：preprint / accepted / peer-reviewed
- 一句话：论文解决了什么问题
- 方法原理：核心机制
- 关键 trick：对复现或效果重要的细节
- 输入与控制层级：传感器、部署观测、高低层关系、动作接口
- 实机证据：平台、任务和已核验的量化结果
- 与当前研究的关系：可借鉴内容与明确差异
- 证据边界：摘要级、全文级或仍待核验
- 链接：primary paper URL

## 其他新论文

- 标题、相关性和链接

## 建议精读顺序

1. 最重要论文及原因
```

Do not force every paper into “must read.” A daily report should normally analyze 3–8 high-priority papers and list the remaining screened papers compactly.
